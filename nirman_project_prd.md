# Nirman Project: AI Workforce Orchestrator
## Product Requirements Document (PRD)

### 1. Project Overview
Nirman is a multi-tenant SaaS platform that automates project management through 10 specialized AI agents. It handles everything from requirement parsing to autonomous execution and delivery review.

### 2. Core Personas
- **Project Manager / Executive**: Monitors health, approves escalations, and manages high-level strategy.
- **AI Agent (Autonomous)**: Performs tasks, identifies risks, and reports progress.

### 3. Key Agent Roles
1. **Intake**: Parses requests.
2. **Planning**: Creates task lists and timelines.
3. **Staffing**: Skill-based matching.
4. **Risk**: Security and carbon footprint monitoring.
5. **Execution Coordinator**: Manages workflows.
6. **Communication**: Stakeholder updates.
7. **Escalation**: Triggers human intervention.
8. **Delivery Review**: Quality validation.
9. **Rebalance**: Dynamic workload optimization.
10. **Project Observer**: Health monitoring.

### 4. Technical Guardrails
- **Multi-Tenancy**: Strict data isolation.
- **Responsible AI**: Bias detection and ethical constraints.
- **Human-in-the-Loop**: Mandatory review for sensitive operations.
- **Security**: JWT and zero-knowledge processing.
